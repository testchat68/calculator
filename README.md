Simple calculator for Linux Mint 22.2 with two memory slots
Please see the picture: Calculator.png
Cut and paste the file calculator.py into HOME folder
Right mouse button on file and choose Options/Permissions/ now check all EXECUTE boxes
Cut and paste the file Калкулатор.desktop on to Desktop
Right mouse button on file and choose Options/Permissions/ now check all EXECUTE boxes
That's it - now you can use the program
